# Google և Yandex․ սեփականության հաստատում

Կայքի տեխնիկական մասում պատրաստ են 33 էջերը, լեզվային հղումները, sitemap-ը, robots.txt-ը, llms.txt-ը, ծառայությունների ու կոնտակտների կառուցվածքային տվյալները։ Telegram-ը կապված է `@armmate_support` username-ին, էլ. փոստը՝ `armmate.support@gmail.com` հասցեին։

Ստորև նշված քայլերը կատարվում են բիզնեսի սեփականատիրոջ Google և Yandex հաշիվներով։ Հաստատման թեգերը տալիս են հենց այդ ծառայությունները․ դրանք կայքի կոդով հորինել հնարավոր չէ։

Ընթացիկ կարգավորումը՝

- Սեփականատերը հայտնել է, որ Google Search Console-ի քայլերն ավարտել է DNS TXT հաստատմամբ և ինդեքսավորման հայտերով։ Հանրային DNS-ում հաստատման գրառումը տեսանելի է։ Օգտագործեք արդեն գոյություն ունեցող property-ն և պահպանեք TXT գրառումը․ նոր HTML թեգ պետք չէ։ Հաշվի հաշվետվություններն ու ինդեքսավորման արդյունքները ստուգվում են սեփականատիրոջ մուտքով։
- Yandex-ի համար սեփականատերը տրամադրել է HTML ֆայլի տարբերակը՝ `yandex_9cce45b71192c2d1.html`։ Այն հրապարակվում է կայքի արմատում՝ <https://armmate.am/yandex_9cce45b71192c2d1.html> հասցեով։ Հրապարակումից հետո Webmaster-ում պետք է սեղմել **Проверить**։ Ֆայլը պահպանեք նաև հետագա հրապարակումների ժամանակ։

## Google Search Console՝ այլընտրանքային HTML հաստատում, եթե երբևէ անհրաժեշտ լինի

1. Քո Google հաշվով բացիր <https://search.google.com/search-console/>։
2. Ընտրիր **Add property → URL prefix** և մուտքագրիր `https://armmate.am/`։
3. Ընտրիր **HTML tag** հաստատման տարբերակը։ Պատճենիր `google-site-verification` թեգի `content` արժեքը։ Գաղտնաբառ կամ մուտքի կոդ ուղարկել պետք չէ։
4. Այդ արժեքը տեղադրվում է `site-config.js` ֆայլի `searchConsoleVerification` դաշտում։ Գործարկվում է `npm run build`, և փոփոխությունները հրապարակվում են։ Թեգը կլինի բոլոր էջերի HTML-ում։
5. Հրապարակումից հետո Search Console-ում սեղմիր **Verify**։
6. **Sitemaps** բաժնում ուղարկիր `https://armmate.am/sitemap.xml`։
7. **URL Inspection** գործիքով ստուգիր անգլերեն, ռուսերեն ու հայերեն գլխավոր էջերը, կարևոր ծառայության և նոր ուղեցույցի էջերը, կատարիր **Test live URL**, հետո՝ **Request indexing**, եթե գործիքը թույլ է տալիս։

Դոմենի ամբողջական property-ն էլ հնարավոր է հաստատել DNS TXT գրառումով, եթե նախընտրում ես դա։ HTML tag տարբերակը հարմար է, երբ կայքի կոդը մենք ենք կառավարում, իսկ DNS վահանակը բացել պետք չէ։

## Yandex Webmaster

1. Քո Yandex հաշվով բացիր <https://webmaster.yandex.com/>։
2. Ընտրիր կայք ավելացնելու տարբերակը և մուտքագրիր `https://armmate.am/`։
3. Սեփականության հաստատման համար ընտրիր **Meta tag**։ Պատճենիր `yandex-verification` թեգի `content` արժեքը։
4. Այդ արժեքը տեղադրվում է `site-config.js` ֆայլի `yandexVerification` դաշտում, էջերը վերակառուցվում և հրապարակվում են։
5. Webmaster-ում ավարտիր հաստատումը։ Sitemap բաժնում ավելացրու `https://armmate.am/sitemap.xml`։
6. Ինդեքսավորման և էջերի ստուգման բաժիններում հետևիր ստացման, սխալների ու որոնման մեջ ընդգրկվելու վիճակին։

## Ինչ կարող է արդեն անել կայքի կառավարիչը

Yandex-ի IndexNow ծանուցման համար առանձին հաշվի մուտք անհրաժեշտ չէ։ Հրապարակված կայքում տեղադրված է պատահական անունով սեփականության հաստատման տեքստային ֆայլ։ `npm run notify:yandex` հրամանը նախ ստուգում է այդ ֆայլի հասանելիությունը, հետո նոր/թարմացված էջերը ուղարկում է `https://yandex.com/indexnow` հասցեին։

Նոյեմբերի 20-ի առաջին ծանուցումը վերաբերում էր 12 էջի։ Այժմ sitemap-ը պարունակում է 33 հասցե։ Հետագա ծանուցումների համար ուղարկիր միայն նոր կամ փոփոխված հասցեները, օրինակ՝ `npm run notify:yandex -- /ru/kontakty/`։ Տեղական արդյունքը պահվում է `qa/yandex-indexnow-submission.json` ֆայլում։ **200** նշանակում է ստացված ծանուցում, **202**՝ ստացված ծանուցում, որի բանալու հաստատումը դեռ ընթացքի մեջ է։ Դրանք չեն նշանակում, որ էջերն արդեն որոնման արդյունքներում են։

IndexNow-ն չի փոխարինում Google Search Console-ին կամ Yandex Webmaster-ի սեփականության հաստատմանը և հաշվետվություններին։ Google-ի համար կայքերի ընդհանուր ինդեքսավորման անստորագիր API չի օգտագործվում։

## Bing Webmaster Tools

1. Քո հաշվով բացիր <https://www.bing.com/webmasters/>։
2. Եթե հասանելի է, ներմուծիր արդեն հաստատված Google Search Console property-ն։ Հակառակ դեպքում ավելացրու `https://armmate.am/` և ընտրիր Meta tag հաստատումը։
3. Իրական `msvalidate.01` թեգի content արժեքը կարող է տեղադրվել `site-config.js` ֆայլի `bingVerification` դաշտում։ Դատարկ արժեքով թեգ չի հրապարակվում։
4. Կայքի թարմացումից հետո ավարտիր հաստատումը և ուղարկիր `https://armmate.am/sitemap.xml`։ Հաշվի հաստատումը դեռ կատարված չի համարվում առանց սեփականատիրոջ կողմից արդյունքը տեսնելու։
