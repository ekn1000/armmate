# Քեզ մնացած քայլերը

Թարմացված է՝ 25 նոյեմբերի 2026։ Կայքի բոլոր 33 էջերի կենդանի տեխնիկական ստուգումը հաջող է։ [Ամբողջ ստուգման հաշվետվությունը](SEARCH-REVIEW-2026-11-25.md) տարբերակում է ստուգված արդյունքներն ու հաշիվների ներսում դեռ չստուգված տվյալները։

## 1. Google Business Profile

Քո ուղարկած նոր սքրինշոթում երևում է հաստատման կապույտ նշանը, իսկ նախկին Processing / Not publicly visible հաղորդագրությունը չկա։ Կառավարման միջերեսը ցույց է տալիս, որ հաստատումն ավարտված է։ Maps-ում անվան որոնմամբ հանրային հայտնվելը դեռ հաստատված չէ։

Քո պարզաբանմամբ՝ պայմանավորվածությունը լինում է առցանց, ծառայությունը կատարվում է համաձայնեցված ձևով, իսկ գրասենյակում զբոսաշրջիկ չեք ընդունում։ Եթե իրական ծառայությունը ներառում է անձնական հանդիպում կամ ուղեկցում, Google-ում համապատասխան ձևաչափը **Service-area business** է։ [Google-ի կանոնները](https://support.google.com/business/answer/3038177?hl=en) նախատեսում են թաքցնել հաճախորդ չընդունող հասցեն և նշել իրական սպասարկման տարածքը։ Միայն հեռավար ծառայությունները Business Profile-ի համար [իրավասու չեն](https://support.google.com/business/answer/13763036?hl=en)։

«Սպասարկման տարածք»-ը աշխարհագրությունն է՝ քաղաքները կամ շրջանները, որտեղ ֆիզիկապես հանդիպում կամ ուղեկցում եք հաճախորդին։ Դա պարտադիր ընդունարան կամ կոնկրետ շենք չէ․ հյուրանոցի կամ օդանավակայանի մոտ հանդիպումը նույնպես կարող է այդ ձևաչափի մաս լինել։ Նշիր իրականում սպասարկվող ուղղությունները։

- Նույն Google հաշվով բացիր [գոյություն ունեցող պրոֆիլը](https://business.google.com/locations)։ Նոր կրկնօրինակ մի ստեղծիր։
- **Edit profile → Location** բաժնում ստուգիր՝ գրասենյակի հասցեն հանրությունից թաքնվա՞ծ է, և սպասարկման տարածքը ճի՞շտ է։
- Ժամերը թող համապատասխանեն իրական հասանելիությանը։ Նախորդ սքրինշոթում նշված **Open 24 hours**-ը տեղին է միայն եթե իսկապես այդպես եք սպասարկում։
- Երբ հանրային **Share profile / Maps** հղումը հասանելի լինի, ուղարկիր այն։ Թվային ID-ից հղում չենք հորինում։ Հղումը կայքի SEO-ն շարունակելու պարտադիր պայման չէ։

## 2. Bing-ի ինդեքսավորումը

Bing Webmaster-ն արդեն միացրել ես․ սկզբից նորից գրանցելու կարիք չկա։ Այսօրվա հանրային `site:armmate.am` հարցումն արդյունք չցուցադրեց։ Դրանից ինդեքսավորման կոնկրետ պատճառը չենք կարող որոշել։

Բացիր [Bing Webmaster Tools](https://www.bing.com/webmasters/) → **URL Inspection** → `https://armmate.am/` → **Bing Index** և ուղարկիր ամբողջ արդյունքը՝ բացված **Crawl / Index** բացատրությամբ։ Նույնը ցանկալի է ստուգել `/en/` և `/ru/` էջերի համար։ Հաջող Live URL-ը և Request indexing-ը դեռ չեն հաստատում, որ էջն ինդեքսում է։

Վերջին փոփոխությունների IndexNow ծանուցման պատասխանը HTTP 200 է՝ վեց էջի համար։ Դա հայտի ընդունման փաստ է, ոչ ինդեքսավորման ապացույց։ Նույն հայտերը բազմիցս ուղարկելու կարիք չկա։

## 3. Google Search Console և ֆավիկոն

Դոմենի DNS հաստատումն արդեն արել ես։ Բացիր [Search Console](https://search.google.com/search-console/) և ուղարկիր՝

- **Indexing → Pages** բաժնի ամփոփ պատկերը և չինդեքսավորման պատճառների աղյուսակը։
- **Performance → Search results** ամփոփումը՝ ցուցադրությունները և սեղմումները գնահատելու համար։

Ֆավիկոնի `https://armmate.am/favicon.png` և `https://armmate.am/favicon.ico` հասցեները հասանելի են։ Google Search-ում իրական ցուցադրումն այսօրվա ավտոմատ փորձով չհաստատվեց, քանի որ Google-ը CAPTCHA ցույց տվեց։ Քո բրաուզերում որոնիր `armmate.am` կամ `site:armmate.am` և ցույց տուր հենց արդյունքը՝ պատկերակով։ Եթե գլխավոր էջի Request indexing-ն արդեն ուղարկել ես, միայն այս ստուգման համար նորից ուղարկելու կարիք չկա։

## 4. Yandex Webmaster

Կայքի Yandex հաստատման HTML ֆայլը հասանելի է, YandexBot-ի անունով էջի հարցումը վերադարձնում է HTTP 200։ Հանրային որոնման փորձը CAPTCHA ցույց տվեց, ուստի ներկա ինդեքսավորման կարգավիճակը դրանով չենք որոշում։ [Yandex Webmaster](https://webmaster.yandex.com/)-ից ուղարկիր կայքի ինդեքսավորման ամփոփումը կամ երևացող կոնկրետ սխալը։

## Գործունեության ընթացքում

- Իրական հաճախորդներին առաջարկիր թողնել իրենց անկեղծ կարծիքը։
- Հյուրանոցների, հոսթելների և ճանապարհորդական հեղինակների հետ զարգացրու իրական համագործակցություն՝ ծառայության ճշգրիտ նկարագրությամբ և կայքի հղումով։
- Իրական հրապարակումների և պրոֆիլների հղումները փոխանցիր, որպեսզի անհրաժեշտության դեպքում կապենք կայքի տվյալներին։
- Շաբաթական նայիր Search Console-ի և Bing-ի հաշվետվություններին։ GitHub-ի **Public search health**-ը ստուգում է հասանելիությունը, ոչ որոնման դիրքերը։ Նոյեմբերի 23-ի պլանավորված ստուգումը հաջող կատարվել է։

GA4-ը կարող է հետագայում օգնել չափել այցերն ու կոնտակտների սեղմումները։ Այն որոնիչում կամ AI որոնման մեջ հայտնվելու պարտադիր պայման չէ։ Հաշիվների ստուգման համար գաղտնաբառեր կամ session cookies մի ուղարկիր․ կարգավիճակների տեքստը կամ սքրինշոթները բավարար են։
